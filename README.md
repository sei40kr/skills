# skills

Agent skills for Claude Code and other agents that read `SKILL.md`.

## Skills

### [creating-notion-page](skills/creating-notion-page)

Create a Notion page in your private space by default, then review it as a first-time reader would.

**Depends on:**

- Notion MCP server

### [commit](skills/commit)

Select hunks, verify the diff that will land, and create a signed commit outside the sandbox — with jj in a jujutsu repository, git otherwise.

**Depends on:**

- [git-surgeon](#git-surgeon) (git repositories only)
- [jj-surgeon](#jj-surgeon) (jj repositories only)
- [good-writing](#good-writing)
- [review](#review)

### [good-writing](skills/good-writing)

Write concise, precise prose: docs, PR descriptions, commit messages, blog posts.

**Depends on:**

- [yomiyasu](#yomiyasu) (optional)

### [grilling](skills/grilling)

Interview you about a plan, decision, or idea in rounds, one frontier of questions at a time. In Claude Code the questions arrive as its prompt UI. Adapted from [mattpocock/skills](https://github.com/mattpocock/skills)' `grilling`.

**Depends on:** none

### [initializing-web-project](skills/initializing-web-project)

Scaffold a web project on a Nix devshell with Bun, TypeScript, and Biome, plus optional libraries.

**Depends on:** none

### [next-dev](skills/next-dev)

Verify Next.js changes without clobbering a running `next dev` server.

**Depends on:**

- [agent-browser](#agent-browser) (optional)

### [review](skills/review)

Review a diff, commit, or pull request and fix what the review finds. So far the only rule sends code comments through `writing-code-comments`.

**Depends on:**

- [writing-code-comments](#writing-code-comments)

### [write-like-yongju](skills/write-like-yongju)

Write Japanese in your own voice: comments and messages to others, issue and PR bodies, and memos.

**Depends on:**

- [good-writing](#good-writing)

### [writing-code-comments](skills/writing-code-comments)

Write code comments and docstrings that explain why, not what.

**Depends on:**

- [good-writing](#good-writing)

## External dependencies

Install these alongside the skills that need them. A skill whose dependency is missing will still load, but the steps that call the dependency won't work.

### git-surgeon

Non-interactive, hunk-level git staging. Provides both the `git-surgeon` CLI and its skill. See [raine/git-surgeon](https://github.com/raine/git-surgeon).

### jj-surgeon

Non-interactive, hunk-level jujutsu operations. Provides both the `jj-hunk-tool` CLI and the `jj-surgeon` skill. See [mvzink/jj-hunk-tool](https://github.com/mvzink/jj-hunk-tool).

### agent-browser

Browser automation CLI for agents. Provides both the `agent-browser` CLI and its skill. See [vercel-labs/agent-browser](https://github.com/vercel-labs/agent-browser).

### yomiyasu

Revises Japanese prose generated by AI. `good-writing` uses it only when the output is Japanese, and works without it otherwise. See [nanaism/yomiyasu](https://github.com/nanaism/yomiyasu).

## Installation

Install as a Claude Code plugin:

```
/plugin marketplace add sei40kr/skills
/plugin install sei40kr-skills@sei40kr
```

The plugin installs every skill above. Install the required external dependencies separately.
