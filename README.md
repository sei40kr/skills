# skills

Agent skills for Claude Code and other agents that read `SKILL.md`.

## Skills

### [creating-notion-page](skills/creating-notion-page)

Create a Notion page in your private space by default, then review it as a first-time reader would.

**Depends on:**

- Notion MCP server

### [git-commit](skills/git-commit)

Stage hunks selectively, verify the staged diff, and create a signed commit outside the sandbox.

**Depends on:**

- [git-surgeon](#git-surgeon)
- [good-writing](#good-writing)

### [good-writing](skills/good-writing)

Write concise, precise prose: docs, PR descriptions, commit messages, blog posts.

**Depends on:**

- [yomiyasu](#yomiyasu) (optional)

### [initializing-web-project](skills/initializing-web-project)

Scaffold a web project on a Nix devshell with Bun, TypeScript, and Biome, plus optional libraries.

**Depends on:** none

### [next-dev](skills/next-dev)

Verify Next.js changes without clobbering a running `next dev` server.

**Depends on:**

- [agent-browser](#agent-browser) (optional)

### [writing-code-comments](skills/writing-code-comments)

Write code comments and docstrings that explain why, not what.

**Depends on:**

- [good-writing](#good-writing)

## External dependencies

Install these alongside the skills that need them. A skill whose dependency is missing will still load, but the steps that call the dependency won't work.

### git-surgeon

Non-interactive, hunk-level git staging. Provides both the `git-surgeon` CLI and its skill. See [raine/git-surgeon](https://github.com/raine/git-surgeon).

### agent-browser

Browser automation CLI for agents. Provides both the `agent-browser` CLI and its skill. See [vercel-labs/agent-browser](https://github.com/vercel-labs/agent-browser).

### yomiyasu

Revises Japanese prose generated by AI. `good-writing` uses it only when the output is Japanese, and works without it otherwise. See [nanaism/yomiyasu](https://github.com/nanaism/yomiyasu).

## Installation

Link each skill you want into your skills directory. For Claude Code:

```sh
git clone https://github.com/sei40kr/skills.git
ln -s "$PWD/skills/skills/good-writing" ~/.claude/skills/good-writing
```

When you install a skill, install its dependencies from the table above as well.
